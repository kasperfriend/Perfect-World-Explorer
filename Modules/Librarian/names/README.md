# Where the Effects names come from

The PW 1.4.2 `gfx.pck` contains internal paths and GFX element `Name:` fields, not a string table of English effect titles. Librarian composes display labels from the two small UTF-8 tables here. It matches the longest term first, retains variant numbers and separators, and leaves already-English text unchanged. For example, `巫师/冷凝术_击中2` becomes `Psychic/Glacial Shards_Impact 2`. The file loader and `BindEle` still receive the original identifiers.

* **Skill names (`skills.tsv`):** Chinese term, skill ID, existing English name. The English column comes from the reference client's `configs.pck` → `configs/skillstr.txt` (not `configs/backup/skillstr.txt`). The native names were matched by numeric name key (`10 × skill ID`) against the [Chinese client skill table](https://github.com/coussiraty/PWClient-152/blob/f321e68953a5502ff5673d6099dab8c193c597a0/PWClient152/ElementCore/ElementSkill/skillstr.txt). Only terms present in the effect corpus were kept; numeric placeholders and ambiguous same-name/different-English pairs were excluded. Matching skill terms in skill paths prefer the installed client's English spelling. A skill term is not proof that a particular skill uses that asset.
* **Effect vocabulary (`effects.tsv`):** translations of folders, visual effects, weapon parts, actors, directions and animation components in the reference archive. Class names follow the repository's Designer catalog. Where identifiable, monster terms use the reference `elements.data` English template name for its model stem (e.g. `深海游荡者` → `Alexor the Butcher`, `血鲷王子` → `Goshiki`). Otherwise these are descriptive translations, not official display titles.

Coverage was checked against all **5,459 `.gfx` paths** and **444 distinct element names** in the reference `gfx.pck` (SHA-256 `d121fe967b9485ce0ef088a4935d395f02f4b17e16a8346d711dd3681be80f49`). This includes names of unsupported effects. To repeat the coverage test, point `PW_LIBRARIAN_REFERENCE_EFFECT_ROOT` at the folder containing that `gfx.pck` and run `cargo test --locked --bin perfect-world-explorer reference_effect_names`. New or modded names reuse known terms and preserve unknown text rather than inventing an English title. No client archives are bundled or sent to a translation service.
