**V: no physical samples.** The [host access blocker](01-sdk.md) prevents
recording RTX/NGX feature admission or actual evaluation. Neither Software
nor Hardware at either resolution has an observed supported/rejected extent
on the specified machine. The [bridge build](01-sdk.md) is not a dispatch.

The ignored physical smoke now takes `PW_TEST_RAY_RESOLUTION=50` or `100`
and verifies the intended extent was used; it reads the actual SDK image at
both 512² → 640² display epochs. A mismatched optimal size logs requested
size, tier callback status and returned size without silently resizing.
`Session::prepare` polls the old submission fence before retiring the current
context; the resize log is emitted on that branch only after the fence is
ready. The CPU stand-in shows extent changes and fence retirement, not an RTX
resize or an NGX admission result. See [delivery](14-delivery.md) for its run.
