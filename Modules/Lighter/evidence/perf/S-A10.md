# A10 — Staged compaction and memory ceiling (S)

`PW_RAY_COMPACT_BLAS=1` builds immutable static BLAS with
`ALLOW_COMPACTION` in the fenced residency lane. Query compact sizes only
after build completion, allocate the compact destination only when it can
save actual charged bytes, and retain old handles through the copy fence.
Publish a chunk only after copies complete. If allocation headroom is
insufficient, keep the valid uncompacted BLAS. Posed BLAS retain the prior
update policy. Startup compaction opts into the A2 paced lane as well.

`PW_RAY_BUDGET_BYTES` can lower the Vulkan raw-resource ceiling from decimal
6.5 GB (minimum 64 MiB); the local heap size can reduce the ceiling further.
This ceiling isn't an accounting claim for total application/driver VRAM.
Travel's 7 GB warning and report distinguish VK_EXT_memory_budget's
whole-process device-local driver estimate from raw charged allocations and
NVIDIA device-wide dedicated-memory telemetry. Sampled BC remains opt-in
under `PW_RAY_BC_TEXTURES`; its tracked image allocations count against the
same raw budget. The existing `world-streaming` worker already builds world
packets and decodes their texture pages away from the render loop; this work
does not make all initial loading or moving texture work asynchronous.
